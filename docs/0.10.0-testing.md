# 0.10.0-alpha.1 — Stability pass

This is a development build, not a verified release. Minecraft 1.21.1 / Fabric / Java 21 remain unchanged.

## Changes
- EVA braking now requires the same equipment as thrust (creative still exempt). Clear stale input after timeout and boundary rescue.
- Cancel rocket countdown immediately when there is no living pilot; reject non-positive clearance heights.
- Atmosphere flood fill rejects fluid-filled origin cells and pressure glass; reject future oxygen power timestamps.
- Clear stale rover controls; Mk II solar charging now uses the vacuum dimension rule.
- Rotate battery priority per network transaction and avoid marking unchanged charge dirty.
- Oxygen equipment and tank counters include the offhand.
- No registry ID, world-generation algorithm, saved NBT layout, recipe or network payload changes.

## Regression checklist

# Lunar Horizons — Alpha 0.2.0

Космический мод для Minecraft Java 1.21.1 / Fabric / Java 21. Экспериментальные исходники, не проверены в игре.

## Сборка
Установи JDK 21. Запусти `build.bat` (Windows) или `bash build.sh` (Linux/macOS); скрипт при необходимости скачает Gradle 8.8. Альтернатива: `gradle build` с Gradle 8.8. JAR появится в `build/libs`. Для игры нужен Fabric Loader 0.16.10 или совместимый и Fabric API 1.21.1. Не устанавливай `-sources.jar`.

## Как играть (предполагаемое поведение)
- Создай тестовый мир. В творческом режиме найди вкладку Lunar Horizons.
- Поставь стартовую площадку и ракету сверху, оставь два свободных блока над ракетой. Надень космический шлем и возьми баллон и топливо.
- Нажми ПКМ по ракете основной рукой, не приседая. Оставайся рядом 5 секунд. Переход на Луну и обратный запуск расходуют по одной порции топлива. Творческий режим не требует топлива и кислорода.
- Баллон расходуется за 10 минут. На Луне уменьшена гравитация. Добывай реголит, лунный камень и кристаллическую руду.
- Тест измерения: `/execute in lunar_horizons:moon run tp @s 0 100 0` в творческом режиме.

## Ограничения
Сборку и запуск необходимо проверить. Ракета — компактный 3D-блок с отсчётом и дымом, не управляемая сущность. Переход мгновенный. Не используй в важных мирах без резервной копии.

## Alpha 0.2.0 — Lunar Atmosphere Update
- Лунный урон от падения отключён для игроков; кислород и остальные источники урона сохраняются.
- Клиентское космическое небо: чёрный фон, звёзды и стилизованная Земля.
- Перерисованные текстуры блоков, предметов и ракеты.
- Сухие пещеры и тоннели в новых лунных чанках; существующие чанки не перегенерируются. Рекомендуется новый тестовый мир.
- Сборка не заменяет тестирование в клиенте и на сервере.

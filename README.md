# Lunar Horizons — Alpha 0.5.8: Rocket Flight

Minecraft Java 1.21.1 / Fabric / Java 21. Экспериментальный мод; компиляция и тесты в игре необходимы.

## Большая ракета «Горизонт»
- Размер: 3×3×8 блоков. Корпус, четыре стабилизатора, сопла, кабина с иллюминаторами, отдельная 3D-модель.
- Построй площадку 3×3 из блоков Launch Pad, нажми предметом Rocket на центральный блок. Оставь над площадкой свободный коридор (до 64 блоков).
- Для старого блока ракеты: расширь площадку до 3×3 и нажми ПКМ по старому блоку, чтобы преобразовать его.
- В выживании надень полный скафандр, возьми ранец, баллон и топливо. ПКМ по ракете: посадка в кабину; R — запуск 5-секундного отсчёта, повторное R — отмена. Одна порция топлива на перелёт.
- Ракета поднимается до 48 блоков, затем происходит переход между измерениями, после чего ракета реально снижается до площадки (до 36 блоков). Полёт автоматический, не свободное управление.
- Shift — выход, в полёте аварийный спуск на поверхность. Shift+ПКМ по пустой стоящей ракете — забрать её в инвентарь.
- На Луне нет урона от падения, есть кислород, пещеры, новые текстуры и Земля в небе. Кислород внутри ракеты не расходуется.
- Ракета сохраняется как сущность. Старые предметы и блоки совместимы через преобразование.
- Не используй экспериментальные версии в важных мирах без резервной копии.

## Сборка
JDK 21, Gradle 8.8: `build.bat` или `bash build.sh`; либо `gradle build`. JAR в `build/libs`. Fabric API для 1.21.1 обязателен. Готовая CI-сборка в GitHub Actions / Artifacts (не sources.jar).

## Проверка
Проверь размещение на 3×3, посадку, отмену, вылет Земля→Луна→Земля в выживании, расход топлива, восстановление мира после перезапуска, вид от первого лица и F5, отсутствие повреждения построек и поведения при двух игроках.

## Alpha 0.5.0 — Moon Exploration

- 5 биомов: равнины, поля кратеров, горы, холодные области и тёмные пустоши. Холодные области являются игровыми биомами, не географическими полюсами. Рельеф и верхние блоки меняются по региональному шуму.

- Лагерь, спутник, лаборатория и жеода — редкие генерационные локации с припасами или кристаллами. Это features, а не структуры для команды /locate.
- ПКМ детектором: ближайший обычный минерал в радиусе 8 блоков (тёмный кристалл намеренно исключён). ПКМ радаром: ближайший поверхностный маяк в пределах 48 блоков по каждой оси, только загруженные чанки. Маяк можно изготовить и установить на базе. Титановый бур работает как быстрая кирка; радиусной добычи нет.
- Редкие метеоритные события у игрока на поверхности: падающий след из частиц, звук и осколки. Нет разрушения блоков и урона; это не физические сущности. Статические кратеры генерируются отдельно.

## Alpha 0.5.8 — Rocket Flight
- Ракета получила сохраняемый бак на 8 единиц топлива. ПКМ топливом по стоящей пустой ракете заправляет одну единицу, Shift+ПКМ — до заполнения; Shift+ПКМ без топлива возвращает ракету и остатки топлива. Полёт расходует одну единицу из бака или, при пустом баке, из инвентаря пилота. Остаток сохраняется при перелёте между измерениями. R в полёте до смены измерения прерывает взлёт и запускает возврат; обратный отсчёт по-прежнему отменяется R. Изменены ускорение и посадочное торможение, HUD показывает вертикальную скорость, бак и инвентарь, перед стартом виден короткий факел. Автоматический маршрут Земля–Луна сохранён.
- Новая площадка прибытия требует опоры под каждым из девяти блоков, пустые промежутки до трёх блоков заполняются лунными кирпичами; непригодная площадка пропускается. Существующая площадка используется как раньше.
- Два сетевых типа сущностей метеоритов с объёмным вращающимся каменным телом, размером примерно 1.4 и 5.5 блока; дым и огонь только дополнение. Сохраняются команды, вероятности, проверка площадки и кратеры. - Генерация местности не изменена. Требуется проверка в игре после CI.

# Lunar Horizons

Экспериментальный космический мод для Minecraft Java 1.21.1 / Fabric / Java 21.

Версия разработки: 0.1.0. Сборка и запуск в игре требуют проверки.

## Сборка
Установите JDK 21 и Gradle 8.8, затем выполните `gradle build`. Готовый JAR появится в `build/libs`. Для игры необходим Fabric API для 1.21.1.

## План
Луна, ракета, кислород, низкая гравитация, ресурсы; далее — управляемые ракеты, кратеры, базы, мобы и подземелья.

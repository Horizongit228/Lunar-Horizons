# Lunar Horizons — Alpha 0.6.4: Engineering Handbook

Minecraft Java 1.21.1 / Fabric / Java 21. Экспериментальный мод; компиляция и тесты в игре необходимы.

## Большая ракета «Горизонт»
- Размер: 3×3×8 блоков. Корпус, четыре стабилизатора, сопла, кабина с иллюминаторами, отдельная 3D-модель.
- Построй площадку 3×3 из блоков Launch Pad, нажми предметом Rocket на центральный блок. Оставь над площадкой свободный коридор (до 64 блоков).
- Для старого блока ракеты: расширь площадку до 3×3 и нажми ПКМ по старому блоку, чтобы преобразовать его.
- В выживании надень полный скафандр, возьми ранец, баллон и топливо. ПКМ по ракете: посадка в кабину; R — запуск 5-секундного отсчёта, повторное R — отмена. Одна порция топлива на перелёт.
- Ракета поднимается до 48 блоков, затем происходит переход между измерениями, после чего ракета реально снижается до площадки (до 36 блоков). Полёт автоматический, не свободное управление.
- Shift — выход, в полёте аварийный спуск на поверхность. Shift+ПКМ по пустой стоящей ракете — забрать её в инвентарь.
- На Луне нет урона от падения, есть кислород, пещеры, новые текстуры и Земля в небе. Кислород внутри ракеты не расходуется.
- Ракета сохраняется как сущность. Старые предметы и блоки совместимы через преобразование.
- Не используй экспериментальные версии в важных мирах без резервной копии.

## Сборка
JDK 21, Gradle 8.8: `build.bat` или `bash build.sh`; либо `gradle build`. JAR в `build/libs`. Fabric API для 1.21.1 обязателен. Готовая CI-сборка в GitHub Actions / Artifacts (не sources.jar).

## Проверка
Проверь размещение на 3×3, посадку, отмену, вылет Земля→Луна→Земля в выживании, расход топлива, восстановление мира после перезапуска, вид от первого лица и F5, отсутствие повреждения построек и поведения при двух игроках.

## Alpha 0.4.6 — Lunar Cave Overhaul
- Удалено вырезание глобальных шумовых полостей из final_density: основной рельеф сохранён, пещеры теперь создают отдельные стандартные cave carvers с лунным тегом заменяемых блоков. Два типа: глубокие тоннели (Y -35…31, вероятность 0.085), неглубокие проходы (Y 24…66, вероятность 0.035). Это вероятности запуска генератора, не доля пустого объёма. Радиусы уменьшены; вода и лава не предусмотрены.
- Входы соединяют существующую неглубокую камеру с поверхностью через шахту 3×3, глубина поиска до 34 блоков, 24 попытки выбора колонки. Не каждый чанк или пещера получат вход.
- Кристаллические наросты разнесены и ограничены тремя за успешную попытку; лунные стебли и обе руды сохранены.
- Старые чанки не перегенерируются. Новый тестовый мир или ранее не посещённые лунные области обязательны для сравнения. Проверка реальной генерации и частоты входов в игре ещё нужна.

## Alpha 0.5.0 — Moon Exploration
- Исправлены ошибки компиляции 0.4.6. Старые шумовые пустоты заменены стандартными лунными cave carvers.
- 5 биомов: равнины, поля кратеров, горы, холодные области и тёмные пустоши. Холодные области являются игровыми биомами, не географическими полюсами. Рельеф и верхние блоки меняются по региональному шуму.
- Кратеры радиусом 12–29 блоков, с валом и редкими метеоритными остатками. Вычисляются из сида мира и координат; каждый чанк изменяет только свои столбцы.
- Титановая руда плавится в слитки, гелий-3 используется для кислородного баллона на 60 минут, лунный лёд подходит для заправки. Гелий-3 как энергетическое топливо запланирован на будущее.
- Лагерь, спутник, лаборатория и жеода — редкие генерационные локации с припасами или кристаллами. Это features, а не структуры для команды /locate.
- ПКМ детектором: ближайший обычный минерал в радиусе 8 блоков (тёмный кристалл намеренно исключён). ПКМ радаром: ближайший поверхностный маяк в пределах 48 блоков по каждой оси, только загруженные чанки. Маяк можно изготовить и установить на базе. Титановый бур работает как быстрая кирка; радиусной добычи нет.
- Редкие метеоритные события у игрока на поверхности: падающий след из частиц, звук и осколки. Нет разрушения блоков и урона; это не физические сущности. Статические кратеры генерируются отдельно.
- Для 0.5.0 рекомендуется новый мир: изменены биомы, рельеф, пещеры, ресурсы. Старые чанки остаются прежними. Компиляция не гарантирует корректную генерацию; проверь загрузку измерения и новые чанки.

## Alpha 0.5.5 — Connected Moon
- Обычные пещеры теперь единая детерминированная сеть: узлы с камерами через каждые 64 блока по координатной сетке, соединения с восточным и южным узлами, извилистые тоннели шириной около 5–7 блоков, глубокие узлы и редкие наклонные выходы. Каждый чанк вырезает только свою часть графа, не загружая соседние чанки для записи. Три независимых carver и прежние искусственные входы отключены. Геоды и закрытые лаборатории остаются отдельными исследовательскими объектами. Сеть не гарантирует проходимость каждого перепада без прыжков или добычи породы. Старые чанки не пересчитываются.
- 8 биомов вместо 5: базальтовые моря (низкие тёмные равнины), анортозитовые хребты (светлая порода и повышенный рельеф), поля ударных выбросов (угловатые обломки). 3 новых блока, модели, добыча, переводы. Кратеры сохраняют исходную породу поверхности.
- 8 текстур поверхности 64×64 в нейтральной и прохладной серой гамме без жёлтого оттенка.
- Кислородная станция, фонарь и маяк используют непрозрачность false и коллизию по фактической модели: соседние грани не должны исчезать рядом с узкими корпусами. Исправление соответствует предполагаемой причине чёрных просветов; требуется проверка в игре.
- Для проверки генерации необходим новый мир либо полностью новые чанки. Компиляция и тестирование в клиенте не равнозначны.

## Alpha 0.5.7 — Lunar Caverns
- Единая пещерная сеть сохраняет координаты узлов 0.5.5. Три размера залов: обычные (радиус 7–10, высота потолка над узлом 5–7), крупные (11–15, 8–11) и редкие мегазалы (18–22, 13–17). Горизонтальные размеры асимметричны, границы неровные, пол волнистый. В крупных залах остаются природные колонны, добавлены редкие диагональные соединения и более широкие участки тоннелей. Глубокие и кристаллические залы получают редкие минеральные наросты, каменные выступы и свисающие образования. Геоды и закрытые лаборатории остаются отдельными объектами. Все операции ограничены текущим чанком.
- Попытки генерации структур: лагерь 1/300 вместо 1/120; спутник 1/240 вместо 1/85; лаборатория 1/400 вместо 1/150; жеода 1/275 вместо 1/110. Фактическая частота ниже из-за проверок местности. Кратеры и руды не изменены.
- Команды с правами уровня 2: `/lunar meteor normal`, `/lunar meteor huge` — падение рядом с источником команды; `/lunar meteor normal at <x> <z>` и `/lunar meteor huge at <x> <z>` — выбрать координаты удара; `/lunar meteor status` — статус; `/lunar meteor cancel` — отмена. Вызов обходит случайную вероятность, но не проверки безопасной площадки. Только Луна, один активный метеорит, без принудительной загрузки чанков. При изменении поверхности удар отменяется.
- Новая генерация только в новых чанках; для проверки желательно создать отдельный мир. Компиляция не подтверждает работоспособность генерации и команд в клиенте.

## Alpha 0.5.8 — Rocket Flight
- Ракета получила сохраняемый бак на 8 единиц топлива. ПКМ топливом по стоящей пустой ракете заправляет одну единицу, Shift+ПКМ — до заполнения; Shift+ПКМ без топлива возвращает ракету и остатки топлива. Полёт расходует одну единицу из бака или, при пустом баке, из инвентаря пилота. Остаток сохраняется при перелёте между измерениями. R в полёте до смены измерения прерывает взлёт и запускает возврат; обратный отсчёт по-прежнему отменяется R. Изменены ускорение и посадочное торможение, HUD показывает вертикальную скорость, бак и инвентарь, перед стартом виден короткий факел. Автоматический маршрут Земля–Луна сохранён.
- Новая площадка прибытия требует опоры под каждым из девяти блоков, пустые промежутки до трёх блоков заполняются лунными кирпичами; непригодная площадка пропускается. Существующая площадка используется как раньше.

## Alpha 0.6.2 — Engineering Update
- Трубы кислорода (6/16 блока) и кабели (4/16 блока) имеют 6 автоматических соединений, узкие объёмные модели с муфтами и коллизиями. Кабели подключаются к энергетическим блокам, трубы — к генератору кислорода и вентиляции. - ПКМ пустой рукой открывает собственный экран оборудования: вход и выход, прогресс, запас, генерация/спрос/подача, заряд сети, число элементов, ошибка переполнения. Управление: включить/выключить, загрузить подходящие ингредиенты из инвентаря, забрать продукт, заправить баллон. Обновляется каждую секунду. Старое управление ПКМ предметом сохранено. Все операции проверяются сервером. Пока это не стандартный контейнер со слотами.

Гелиевые генераторы работают по спросу, выключенные машины сохраняют запасы, равноприоритетные потребители получают циклическую очередь при нехватке энергии. Лимит энергосети 1024, герметичного помещения 2048 клеток (до 24 от игрока по оси), кислородной сети 512. Отдельные лицевые панели машин поворачиваются при установке, общие боковые и верхние корпуса.
- Система остаётся внутренней энергосистемой Lunar Horizons, без совместимости с энергосистемами других модов; механика давления упрощённая. Рекомендуется резервная копия, проверить в игре.
